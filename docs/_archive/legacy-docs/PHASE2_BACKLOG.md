## Non-negotiable invariants

- Derived chunks, indexes, vectors, graphs, reports, and sync state are rebuildable; canonical output remains unmodified.
- Every retrieval/derived result retains source hash and span citation. No automated result claims human review.
- Redacted indexing is end-to-end: suppressed values never enter chunks, FTS excerpts, vectors, MCP, or events.
- Search is local FTS5 first; embeddings/Qdrant/network behavior requires explicit configuration and permissions.
- Sync defaults to dry-run; apply/delete needs explicit `--apply`, and user-modified output is never silently removed.
- Generated graph edges are only `unverified`; claim findings are only potential conflicts, never factual conclusions.
