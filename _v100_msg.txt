feat(v0.10.0): `headcleaner view` — OKF bundle HTML viewer

Adopted from `scaccogatto/okf-skills` (MIT, 312 stars). Vendored as
`src/headcleaner/viewer.py` with the original 432-LOC script preserved
verbatim (HTML/CSS/JS template is byte-identical) and a Python API
added on top.

What the new subcommand does:
- `headcleaner view <bundle>` writes `<bundle>/viz.html` by default
- `headcleaner view <bundle> -o out.html` writes to a custom path
- `headcleaner view <bundle> --open` opens the result in the browser
- `headcleaner view <bundle> --serve --port 8765` serves it locally
- Layout switcher: cose / concentric / breadthfirst / circle / grid
- Trust-tier badge in the detail panel (unverified / machine-confirmed
  / human-reviewed), per OKF v0.2 §5.3 — derived, never stored
- Backlinks computed from markdown links AND `sources[].resource`
- OKF v0.1 + v0.2 support (legacy `timestamp` mapped to `generated.at`)

Architecture:
- `src/headcleaner/viewer.py` — the vendored module (~430 LOC body +
  ~120 LOC Python API)
- `src/headcleaner/cli.py` — new `view` Click subcommand
- `tests/test_viewer.py` — 15 unit tests
- `tests/test_view_cli.py` — 6 CLI tests
- `docs/VIEWER.md` — usage doc
- `docs/CHANGELOG.md` — v0.10.0 entry
- `README.md` — CLI surface updated
