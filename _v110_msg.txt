feat(v0.11.0): `headcleaner mcp` — 10 OKF tools for any MCP agent host

Run headcleaner as an MCP server over stdio, exposing OKF bundles to
Claude Code, Cursor, and any MCP-capable agent. Tool verbs and
semantics follow `travisjakel/okf-mcp` (Apache-2.0) so the two
servers are interchangeable.

Tools (10, all named `okf_*`):
- okf_list_bundles — list loaded bundles
- okf_search — substring search across title/description/body
- okf_get_concept — read one concept (frontmatter + body), wikilink
  resolution by id / title / filename stem
- okf_context — concept + BFS neighborhood as markdown blob
- okf_related — top-k by link degree
- okf_impact — outbound / inbound / transitive links
- okf_doctor — health score + per-rule findings
- okf_diff — file changes since last load
- okf_refresh — re-ingest after changes
- okf_sql — read-only SELECT over concepts/links tables

Architecture:
- src/headcleaner/mcp.py (~530 LOC) — the server + BundleRegistry
- src/headcleaner/cli.py — new `mcp` Click subcommand
- src/headcleaner/viewer.py — new build_with_unresolved() helper that
  returns broken-link records (build() silently drops them)
- tests/test_mcp.py — 23 unit tests (direct function calls; transport
  is covered by FastMCP's own suite)

Install:
    uv pip install "headcleaner[mcp]"
    headcleaner mcp ./out/okf                   # one bundle
    headcleaner mcp wiki=./out/okf notes=./vault  # named bundles
    claude mcp add headcleaner -- headcleaner mcp ./out/okf
