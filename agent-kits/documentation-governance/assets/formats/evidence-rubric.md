# Audit evidence rubric

| Disposition | Use it when | Required evidence |
|---|---|---|
| `updated` | The change affects the page and the page was edited. | State the affected contract/behavior, named section, and validation performed. |
| `reviewed` | The page is in scope but remains accurate. | State the phase change considered and why the existing wording remains accurate. |
| `not-applicable` | The page cannot be affected by the phase. | State the page's subject and why no relationship exists; do not write only “no change.” |

`pending` is valid only while an audit is `in_progress`. `complete` audits cannot contain it.

Audits are evidence ledgers, not release notes. They must not contain credentials, customer data, private URLs, or unreviewed claims.
